# Captures — le carnet d'adresses

Engendrées par le banc navigateur, jamais prises à la main, sur **banc-fastmail** avec le compte de
démonstration `kbt` (contacts fictifs de la vitrine) ; rien n'est écrit dans le compte.

| Image | Ce qu'elle montre |
|---|---|
| `contacts-carnet.png` | Le carnet ouvert depuis la barre des applications : la liste par lettre, la recherche, les boutons |
| `contacts-fiche.png` | La fiche d'un contact ouverte à droite, onglets **Contact**, **professionnel**, **Chiffrement** |

Les refaire, depuis la racine de la suite :

    MOTDEPASSE="$(cat /root/.secrets/kbt.motdepasse)" sh tools/manuel/captures-guides.sh
