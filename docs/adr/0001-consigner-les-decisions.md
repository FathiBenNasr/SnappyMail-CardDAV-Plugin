# 0001 — Consigner les décisions d'architecture

- État : acceptée
- Date : 2026-10-24

## Contexte

Les raisons d'un choix se perdent plus vite que le code qu'il a produit. Une session ou un
développeur qui reprend SnappyMail-carddav doit pouvoir savoir pourquoi les choses sont ainsi avant de les
changer.

## Décision

Chaque décision structurante fait l'objet d'un fichier `docs/adr/NNNN-titre.md` au format MADR :
contexte, options envisagées, décision, conséquences. Un ADR accepté ne se réécrit pas : une
nouvelle décision le remplace et le cite.

## Conséquences

La table « Décisions » de [ARCHITECTURE.md](../ARCHITECTURE.md) liste les ADR et leur état.
