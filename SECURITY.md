# Signaler une vulnérabilité · Reporting a vulnerability

**Français** — Si vous pensez avoir trouvé une faille dans SnappyMail-carddav, écrivez à
**contact@convergent.tn** avec l'objet « Sécurité — SnappyMail-carddav ». Merci de ne pas ouvrir de
ticket public et de ne pas divulguer la faille avant notre réponse. Nous accusons réception
sous cinq jours ouvrés et vous tenons informé jusqu'à la correction.

**English** — If you believe you have found a vulnerability in SnappyMail-carddav, write to
**contact@convergent.tn** with the subject "Security — SnappyMail-carddav". Please do not open a public
issue or disclose the flaw before we reply. We acknowledge within five working days and keep
you informed until it is fixed.

Versions maintenues · Supported versions : la dernière version publiée · the latest release.
